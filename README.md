# 画面语法 · 视频提示词工作台

一个面向 Seedance 视频创作的中文提示词撰写工具。包含 17 个类别、333 个术语，支持搜索、勾选、收藏、自定义词条、逐镜头画面构成、实时预览、本地保存、详细案例库，以及可选的 AI 建议。

## 启动

需要 Node.js 20 或更新版本，无须安装 npm 依赖。查看内置案例原文时，本机需要联网并能使用系统 `curl` 命令。

```bash
npm start
```

浏览器打开 `http://127.0.0.1:3000`。如需更换端口，可在 `.env` 中设置 `PORT`。

## 配置 AI

在平台右上角打开“设置”，填写兼容接口地址、模型名称、API 密钥并保存，可直接测试连接。连接信息保存在这台电脑的 `local-data/ai-settings.json`，密钥不会出现在浏览器草稿或导出的 JSON 中。文件仅供本机用户读取。

也可以将 `.env.example` 复制为 `.env`，填写默认连接：

```text
AI_BASE_URL=https://你的兼容接口地址/v1
AI_MODEL=模型名称
AI_API_KEY=你的密钥
```

模型服务需兼容 OpenAI Chat Completions 格式。设置页保存的连接优先于 `.env`。修改 `.env` 后需重启服务。设置页还可切换两项 AI 功能各自的内置规则，并复制、编辑、保存自己的规则。若服务公开部署，请自行配置访问控制和 HTTPS；当前默认仅监听本机 `127.0.0.1`。

## 使用

1. 在中栏写下一句创意并设定比例、时长和生成方式。全片设定只写跨镜头保持不变的内容。
2. 在左栏指定词汇加入“全片设定”“通用镜头”或某个镜头；在中栏各模块也可直接搜索、勾选。基础设定词汇始终归入全片设定，镜头类词汇不会误归入全片设定。取消勾选不会删除自己写的文字。
3. 每张镜头卡都可独立描述画面构成、动作、机位、运镜、光影、声音等；转场附着在前一镜头与下一镜头之间。时间重叠和超时会提示。
4. “案例库”先展示提示词原文，再展示结构拆解与学习用重写示范。12 个内置案例的原文按需从固定官方或 GitHub 来源读取，不随安装包保存；离线时可继续查看拆解。自建案例的完整提示词会保存在本机草稿中，可编辑、导入和导出。
5. 在右栏检查、编辑、复制或下载最终提示词。直接修改预览后，点击“重新生成”会先确认覆盖。通过设置导出 JSON，备份草稿、收藏、自定义词条和自建案例。

AI 拆解只把建议填入空白字段，不覆盖已经写好的内容；AI 优化会提供可预览的新版本。未配置 AI 时，其他功能仍可使用。旧版浏览器草稿会自动迁移，原始数据另存为本地备份键。

勾选景别与构图、机位、运镜、焦点、灯光、转场、拍摄设备和镜头风格词汇后，最终提示词只写专业名词；动作、场景和声音等类别仍写具体描述。手动输入的文字原样保留。
